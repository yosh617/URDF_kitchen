# URDF Kitchen Studio - クイックスタートガイド

## はじめに

このガイドでは、URDF Kitchen Studioを使って初めてのURDFファイルを作成する手順を説明します。

## 準備

### 必要なもの

1. STLファイル（ロボットパーツのメッシュデータ）
2. Python環境（3.9, 3.11, 3.12推奨）
3. 必要なライブラリ（numpy, PySide6, vtk, NodeGraphQt）

### インストール確認

```bash
python urdf_kitchen_main.py
```

アプリケーションが起動すれば準備完了です！

## 基本ワークフロー

### Step 0: プロジェクト作成

1. アプリケーション起動後、ホーム画面が表示されます
2. 「新規プロジェクトを作成」ボタンをクリック
3. プロジェクト保存先フォルダを選択
4. プロジェクトが作成され、ワークスペースに切り替わります

**Tips**: 初めての場合は「サンプルプロジェクト(roborecipe2)を開く」で練習できます！

---

### Step 1: STL Editor（オプション）

**目的**: STLファイルの座標系を調整

このステップは、STLファイルの座標系が適切な場合はスキップできます。

#### 操作手順

1. 「Open STL」ボタンでSTLファイルを開く
2. 3Dビューでメッシュを確認
3. 必要に応じて変換を適用：
   - **移動**: X, Y, Z座標の調整
   - **回転**: X, Y, Z軸周りの回転（度数法）
   - **スケール**: サイズ変更
   - **軸反転**: X, Y, Z軸の反転
4. 「Save STL」で保存
5. **「📤 Parts Editorに送る」ボタンをクリック** → 自動的にParts Editorに移動

**便利機能**:
- 「Reset View」: カメラ位置をリセット
- 「Wireframe」: ワイヤーフレーム表示切替
- 「Show Axes」: 座標軸表示
- 「Center to Origin」: 原点に中心化

---

### Step 2: Parts Editor（必須）

**目的**: パーツに接続点と物理パラメータを設定

#### 2-1. STL読み込み

- Step 1から送信された場合: 自動で読み込まれます
- 手動の場合: 「Load STL」ボタンでファイル選択

#### 2-2. 接続点の設定

1. 「Connection Points」タブを開く
2. 「Add Point」で接続点を追加
3. 接続点の情報を入力：
   - **Name**: 接続点の名前（例: joint_shoulder）
   - **X, Y, Z**: 接続点の座標
4. 「Add/Update」で確定
5. 3Dビューで接続点が球体で表示されます

**Tips**: 
- 最大8個の接続点を設定可能
- 接続点は次のパーツとの接続位置になります
- 座標は3Dビューで確認しながら調整

#### 2-3. 物理パラメータの設定

「Physical Properties」タブで以下を設定：

1. **2つのパラメータを入力**（3つ目は自動計算されます）:
   - Volume（体積）
   - Density（密度）
   - Mass（質量）
2. 「Calculate」をクリック

**自動計算オプション**:
- 「Auto from STL」: STLから体積を自動計算

#### 2-4. 重心の計算

「Center of Mass」タブ:
- 「Calculate from STL」をクリック
- STLメッシュから重心が自動計算されます

#### 2-5. 慣性テンソルの計算

「Inertia Tensor」タブ:
- **精密計算**: 「Calculate Precise」（推奨）
- **バウンディングボックス近似**: 「Calculate BBox」（高速だが精度低）

#### 2-6. パーツXMLの保存

1. 「Save Part XML」ボタンをクリック
2. ファイル名を入力（例: shoulder.xml）
3. **「📤 Assemblerに送る」ボタンをクリック** → 自動的にAssemblerに移動

---

### Step 3: Assembler（必須）

**目的**: パーツを組み立ててロボット構造を作成

#### 3-1. Base Linkの追加

1. ツールバーの「Add Base Link」ボタンをクリック
2. ノードグラフにbase_linkノードが追加されます
3. base_linkのSTLファイルを設定（プロパティパネル）

#### 3-2. パーツノードの追加

1. 「Add Part」ボタンをクリック
2. パーツノードが追加されます
3. ノードのプロパティを設定：
   - **STL File**: パーツのSTLファイル
   - **XML File**: Step 2で作成したXMLファイル
   - **Mass**: 質量（XMLから自動読み込み）

#### 3-3. ノード間の接続

1. 親ノードの**出力ポート**（右側）をドラッグ
2. 子ノードの**入力ポート**（左側）にドロップ
3. 接続が作成されます

**階層構造の例**:
```
base_link (胴体)
  ├─ shoulder_l (左肩)
  │   └─ arm_l (左腕)
  └─ shoulder_r (右肩)
      └─ arm_r (右腕)
```

#### 3-4. 3Dプレビュー

「3D Preview」タブで組み立て状態を確認：
- ノードを追加/接続するたびに自動更新
- カメラ操作でいろいろな角度から確認

#### 3-5. ツリービュー

「Tree View」タブでロボット構造を確認：
- base_linkからの階層がテキスト表示されます
- 「Refresh Tree」で更新

#### 3-6. URDFエクスポート

1. 「Export URDF」ボタンをクリック
2. 保存先とファイル名を指定
3. URDFファイルが生成されます！

## 便利機能

### プロジェクト管理

- **保存**: プロジェクトデータは自動保存されます
- **読み込み**: ホーム画面の「Recent Projects」から再開
- **クローズ**: メニューバー「Project」→「Close Project」

### 言語切り替え

- ホーム画面右上の言語選択
- メニューバー「Language」から日本語/英語を選択

各モードで作業完了後、専用ボタンで次のモードに自動送信：
- STL Editor → 「📤 Parts Editorに送る」
- Parts Editor → 「📤 Assemblerに送る」

## よくある質問

### Q1: STLファイルが読み込めない

**A**: 以下を確認してください：
- ファイルがASCII STL形式であること
- ファイルパスに日本語が含まれていないこと
- ファイルが破損していないこと

### Q2: 物理パラメータの計算結果がおかしい

**A**: 
- STLメッシュが閉じていることを確認
- 単位系（mm/m）を確認
- 密度の単位に注意（kg/m³）

### Q3: ノードグラフで接続できない

**A**:
- 親→子の方向（出力→入力）を確認
- 循環接続（ループ）になっていないか確認

### Q4: URDFが正しく生成されない

**A**:
- base_linkが存在するか確認
- 全ノードが接続されているか確認（孤立ノードがないか）
- ツリービューで構造を確認
